# ZetaFile

Administrador de archivos moderno para Android desarrollado en Kotlin.

## 📌 Estado del proyecto

🚧 En desarrollo.

## 🎯 Objetivo

ZetaFile es un administrador de archivos diseñado para Android con una interfaz moderna, alto rendimiento y funciones avanzadas para la gestión de archivos locales.

## ✨ Características previstas

- Navegación rápida por el almacenamiento.
- Acceso mediante Shizuku a directorios protegidos.
- Diseño moderno basado en Material Design.
- Soporte para copiar, mover, renombrar y eliminar archivos.
- Búsqueda rápida de archivos.
- Información detallada de archivos y carpetas.
- Compatibilidad con Android moderno.

## 🛠️ Tecnologías

- Kotlin
- Android SDK
- AndroidX
- Material Design
- RecyclerView
- Shizuku (opcional para funciones avanzadas)
